# Nooki — магазин и конвейер ассетов

## 1. Магазин

### Главная идея
Магазин — не витрина, а ещё один повод для пары взаимодействовать. Всё, что покупается, попадает в **общую** комнату и влияет на **общего** питомца.

### Экономика
- **Одна валюта — монеты, кошелёк общий на двоих.** Две валюты (как silver/gold fish в Neko Atsume) работают в играх, но в приложении для пары путают и выглядят как давление.
- **Монеты зарабатываются только совместными действиями.**

  | Действие | Монеты |
  |---|---|
  | Ежедневный вопрос (оба ответили) | 30 |
  | Покормить или погладить Mochi (лимит в день) | 5 × 3 |
  | Добавить момент (фото) | 10 |
  | Серия 7 дней подряд | 100 |
  | Годовщины: 100-й день, полгода, год | 300–1000 |

  Активная пара получает около 60–80 монет в день, это одна покупка среднего уровня в 3–5 дней.
- **Цены.** Мелкий декор 40–120, мебель 150–400, лежанки и игрушки Mochi 200–600, тема комнаты 1500+.
- **Платная часть: подписка Nooki Plus**, без продажи монет за деньги. Подписка даёт ×1.5 к монетам, доступ к Plus-коллекциям и один сезонный предмет в месяц. Так устроен Finch: монеты за самозаботу, подписка расширяет магазин и даёт редкие предметы.

### Механики, которых нет у конкурентов
1. **Подарок партнёру.** Купил предмет и отметил «это подарок» — в комнате появляется коробка с бантом. Партнёр получает пуш, тапает по коробке, она раскрывается с анимацией. Это главная фича магазина: покупка превращается в жест.
2. **Совместная покупка.** Дорогие предметы (от 800) требуют «да» от обоих. Карточка «Л. хочет Кресло-облако 🪑, скидываемся?» и кнопка «Да». Повод поговорить, а не просто потратить.
3. **Вишлист пары.** Каждый ставит ♥ на предметы, общий список видят оба. Дешёвый и сильный материал для подарков.
4. **Предметы годовщин нельзя купить.** «Лампа 100 дней», «Окно первого снега» — открываются по Day N. Эмоциональная ценность выше любой цены.
5. **Предметы влияют на настроение Mochi.** Когтеточка поднимает «Curious», новая лежанка — «Rested». Мягко, без pay-to-win: кот не страдает, если ничего не покупать.

### Структура каталога
- **Сегодня** — 4 предмета дня, обновление в 00:00 по локальному времени пары. Ротация из каталога со скидкой 20% на один.
- **Коллекции** — наборы по 5–8 предметов в одном стиле («Лесной домик», «Японский чайный», «Зимний»). Собрали всю коллекцию — особая анимация Mochi или эффект за окном.
- **Категории** (постоянный каталог):
  - Мебель — кровати, кресла, столы, полки
  - Декор — растения, лампы, картины, гирлянды
  - Для Mochi — лежанки, игрушки, ошейники, шапочки
  - Комната — обои, пол, окно и вид за ним, погода
- **Сезонное** — Хэллоуин, Новый год, 14 февраля. Ограничено по времени, возвращается через год.

### Экран магазина
```
┌──────────────────────────────┐
│ Shop                 ⭐ 560 + │
│ ┌──────────────────────────┐ │
│ │  [3D-карусель коллекции] │ │  ← hero: сезонная коллекция, крутится
│ │  Зимний домик · 3/6      │ │
│ └──────────────────────────┘ │
│ (Сегодня)(Мебель)(Декор)(Mochi)(Комната)
│ ┌────────┐ ┌────────┐        │
│ │ рендер │ │ рендер │        │  ← карточки: рендер на мягком фоне,
│ │ Кресло │ │ Лампа  │        │     цена-пилюля, ♥ вишлист,
│ │ ⭐ 240 │ │ ⭐ 90  │        │     бейдж «Подарок от М.» / «Plus»
│ └────────┘ └────────┘        │
└──────────────────────────────┘
```
- **Детальная карточка** — шит с 3D-моделью, которую можно крутить пальцем, и тремя кнопками: «Купить», «Подарить», «♥».
- **«Примерить в комнате»** — главное преимущество 3D. Предмет появляется в диораме полупрозрачным в своём слоте. Покупка — тут же, без выхода из комнаты.

### Размещение
Без свободной расстановки на старте. Комната — **набор слотов**: `floor.corner.left`, `floor.center`, `wall.left.1`, `wall.right.shelf`, `window`, `pet.bed` и т.д. У каждого предмета тег слота, при покупке он встаёт в свободный слот или заменяет текущий (старый уходит в «Инвентарь»). Это проще в разработке, всегда выглядит аккуратно и не требует от художника продумывать коллизии.

// note: слоты ограничивают кастомизацию; апгрейд — сетка 6×6 на полу с drag-to-place, когда каталог вырастет до 100+ предметов.

## 2. Конвейер ассетов (пункт 4)

### Проблема
Каждый предмет магазина — 3D-модель. При ручной работе контент закончится через месяц.

### Решение: три источника, один стиль

| Источник | Что даёт | Когда |
|---|---|---|
| **CC0-паки** (KayKit, Tiny Treats, SereinArt) | Сотни готовых предметов бесплатно | Основа каталога, старт |
| **Blender-скрипты** (как `Tools/make_cat.py`) | Уникальные «геройские» предметы и всё для Mochi | Коллекции, сезонное |
| **Код из примитивов** (как сейчас `DioramaScene`) | Стены, пол, окно, вариации цвета | Темы комнаты |

### Как сделать всё одним стилем
Ключевая находка: **KayKit и Tiny Treats текстурируются одной градиентной атлас-текстурой 1024²**. Значит, одно перекрашивание атласа в палитру Nooki (медовый, терракота, кремовый, пыльно-розовый) переводит весь пак в наш стиль. Делается одним Blender-скриптом:

1. Импорт glTF.
2. Замена атласа на наш.
3. Унификация материала: roughness 0.85, без металла — как у `Clay.matte`.
4. Bevel 0.5–1 мм — мягкие «пластилиновые» грани.
5. Нормализация масштаба: 1 unit = 1 м, pivot по низу.
6. Экспорт USDZ + рендер превью 512² для карточки (тот же пайплайн, что `MochiPortrait`).

Итог — `Tools/import_pack.py <pack_dir>`, который превращает пак в набор `Item_<id>.usdz` + `Item_<id>.png` + запись в `catalog.json`.

### Стайлгайд (требования к любому предмету)
- **Палитра** — 12 цветов, только из атласа Nooki.
- **Полигоны** — до 3k треугольников на предмет, до 8k для «героя».
- **Материалы** — один на предмет, атлас; эмиссия только для источников света.
- **Формы** — скруглённые, без острых углов, пропорции чуть «приплюснутые» (chibi).
- **Масштаб** — как у реальной мебели, умноженный на 0.18 (масштаб диорамы).

### Доставка
- `catalog.json` с сервера: id, название, цена, категория, слот, коллекция, даты доступности, эффекты на настроение.
- USDZ грузятся по требованию (Background Assets / CDN) и кешируются. Приложение не растёт, новые коллекции выходят без апдейта в App Store.
- Предметы годовщин и стартовые — внутри бандла.

### Куда смотреть для вдохновения
**Бесплатные, коммерческое использование (CC0):**
- [KayKit Furniture Bits](https://kaylousberg.itch.io/furniture-bits) — 50+ предметов, один градиентный атлас, лучший кандидат для перекраски.
- [Tiny Treats](https://tinytreats.itch.io/collection-1) — самый «милый» стиль. Наборы Homely House, Charming Kitchen, Pleasant Picnic, совместимы по размерам с KayKit.
- [SereinArt Bedroom](https://sereinart.itch.io/bedroom-furniture) / [Living Room](https://sereinart.itch.io/living-room-furniture) / [Kitchen](https://sereinart.itch.io/kitchen-furniture) — cozy-стиль, есть glTF.
- [Kenney Furniture Kit](https://opengameart.org/content/furniture-kit) и [Quaternius Furniture](https://opengameart.org/content/furniture-low-poly) — нейтральная база, проще по стилю.
- [Cozy Low-Poly Furniture CC0](https://nemeliss.itch.io/furniture-lowpoly-cc0) — 22 предмета.

**Платные, как ориентир по качеству и объёму:**
- [ithappy Furniture Cute](https://ithappystudios.com/interiors/furniture-cute-kit) — сотни предметов в «мультяшном» стиле, близко к референсу.
- [Mizumi 3D Stylized Cozy Furniture](https://mizumiart.itch.io/3d-stylized-cozy-furniture-pack-1) — хороший уровень «уюта».

**Продукты, у которых стоит подсмотреть механику:**
- **Finch** — валюта за действия, магазин одежды и мебели, подписка добавляет редкие предметы.
- **Neko Atsume** — предметы влияют на то, какие коты приходят, и это мотивирует покупать без давления.
- **Animal Crossing** — ротация каталога и сезонные предметы.

Перед использованием любого пака проверить лицензию на странице загрузки: условия меняются.
